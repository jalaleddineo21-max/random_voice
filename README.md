# random_voice # Random Voice — شروع پروژه MVP

این بسته، اولین اسکلت اجرایی پروژه است؛ هنوز محصول آماده انتشار نیست.
در این نسخه:
- رابط اولیه Flutter برای Android/iOS
- صفحه خانه، انتخاب فیلتر، صفحه تماس و وضعیت‌های اتصال
- بک‌اند نمونه Node.js برای صف اتصال دو نفر و صدور توکن LiveKit
- GitHub Actions برای ساخت APK آزمایشی اندروید در فضای ابری

## نکته مهم
برای تماس واقعی باید سرور backend را روی یک سرویس میزبانی اجرا کنید، حساب LiveKit Cloud بسازید و مقادیر محیطی را تنظیم کنید. توکن LiveKit نباید داخل اپلیکیشن هاردکد شود. این نمونه صف در حافظه نگهداری می‌شود و درخواست نفر اول را تا ۲۵ ثانیه باز نگه می‌دارد تا نفر دوم با فیلتر سازگار برسد؛ برای تولید نهایی باید Redis، WebSocket/صف پایدار، محدودیت نرخ، مدیریت گزارش‌ها و ذخیره‌سازی پایدار اضافه شود.

## ساخت APK بدون کامپیوتر
1. یک حساب GitHub بسازید: https://github.com
2. یک Repository جدید با نام `random-voice-mvp` بسازید.
3. فایل‌های این بسته را در Repository آپلود کنید (در GitHub موبایل می‌توانید از Add file استفاده کنید).
4. وارد تب Actions شوید و workflow با نام `Build Android APK` را اجرا کنید.
5. پس از پایان موفق، در بخش Artifacts فایل `random-voice-debug-apk` را دانلود کنید.

Workflow برای ساخت، یک پروژه Flutter اندروید موقت ایجاد می‌کند؛ بنابراین لازم نیست پوشه‌های تولیدشده Android را دستی بسازید.

## اجرای backend نمونه
در پوشه backend:
```bash
npm install
cp .env.example .env
npm start
```
مقادیر `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` را از LiveKit Cloud بگیرید.
برای تست عمومی، backend را روی HTTPS میزبانی کنید. آدرس backend را در فایل `mobile/lib/config.dart` قرار دهید. هر دو گوشی باید همین backend و یک پروژه LiveKit را استفاده کنند.

## وضعیت اتصال
اپ برای دریافت توکن و اطلاعات اتاق از endpointهای backend استفاده می‌کند. تا وقتی backend و LiveKit تنظیم نشده‌اند، تماس واقعی برقرار نمی‌شود.

## محدودیت‌ها و کارهای لازم پیش از انتشار
- تأیید سن و سیاست حفاظت از افراد زیر سن قانونی
- گزارش، بلاک و پنل رسیدگی به گزارش‌ها
- جلوگیری از اتصال مجدد افراد بلاک‌شده
- Rate limiting و ضدربات
- مدیریت قطع اینترنت و بازیابی تماس
- تست کیفیت صدا روی اینترنت موبایل و Wi-Fi
- سیاست حریم خصوصی، شرایط استفاده و حذف حساب/داده
- تنظیم TURN و بررسی هزینه ترافیک
- پیاده‌سازی صف پایدار با Redis و چند نمونه backend
- تست امنیتی و تست روی دستگاه‌های واقعی
